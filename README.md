# Scrapbook Checklist - Don't Starve Together

![website demo](./docs/demo.png)

Since Don't Starve Together doesn't have achievements, many people use the Scrapbook as an alternative.

Unlocking entries can be a really tough task since theres thousands of them, and thinking this way i've made this website so you can check which entries are missing from your own scrapbook!

This application uses simple html system, source in json data and static asset images for each entry.
